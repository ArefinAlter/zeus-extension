# Permissions

Written for the Chrome Web Store review (and reused for Firefox AMO). Every permission the extension can ever hold is listed here with its justification. `npm run check` fails if a manifest declares anything that is not on this list, so this document and the manifest cannot drift apart silently.

## Single purpose

Zeus finishes downloads that a browser could not finish. When a download is interrupted, the extension offers it to the Zeus app running on the same computer, shows the user what Zeus asks permission for, and, only after the user agrees for a specific website, lets Zeus use the user's own signed-in session for that website so the file can be completed.

## Install-time permissions

| Permission        | Why it is needed                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | What it is not used for                                                                                                                                                                                                                                               |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `downloads`       | Observe `chrome.downloads.onChanged` and `onErased` to notice interrupted downloads, read the download item (URL, size, interrupt reason, whether the browser can resume) to build the offer to Zeus, list the user's recent unfinished downloads in the popup so the user can send one to Zeus, and start and immediately cancel a download to learn the final URL of an expired link (`url_refresh.download_api`, used only when the daemon asks and the user consented for that site). | The extension never reads, opens or deletes the user's finished files, never changes the browser's download settings and never starts a download the user did not ask Zeus to rescue. Downloads that the browser or an antivirus blocked as unsafe are never offered. |
| `nativeMessaging` | The only way to talk to the Zeus app: `runtime.connectNative("dev.zeus.native_host")`. All handoff, approval and session traffic goes over this port. The browser lets only extensions named in the host manifest connect.                                                                                                                                                                                                                                                                | No other process is contacted. There is no network connection to a Zeus server (none exists).                                                                                                                                                                         |
| `storage`         | Keeps small, non-secret state across service-worker restarts: the user's consent records (site, scope, expiry), the sites the user chose to block, which offers were sent, the event cursor, a random per-profile identifier and two settings. `storage.session` holds the replay guard for session requests.                                                                                                                                                                             | Cookies, URLs with query strings, file names and file contents are never stored.                                                                                                                                                                                      |
| `notifications`   | Tells the user that Zeus needs a decision, that a rescued file was saved, or that a download could not be finished.                                                                                                                                                                                                                                                                                                                                                                       | Notifications never decide anything; a decision needs a click on a button in the extension's own popup.                                                                                                                                                               |
| `alarms`          | A 30-second alarm that reconnects to the Zeus app only while Zeus has work pending (an offer, an approval or a running job), because a Manifest V3 service worker is terminated when idle. The alarm is removed when nothing is pending.                                                                                                                                                                                                                                                  | No polling of any website.                                                                                                                                                                                                                                            |

## Optional permissions (requested at runtime, from a user click)

| Permission                                                             | When it is requested                                                                                                                                                                                  | Why                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cookies`                                                              | In the click handler that approves a website for Zeus, together with the host permission for that one website.                                                                                        | To read, for one approved website only, the cookies the browser would send for the download URL, so that Zeus can complete the download as the signed-in user. Each release is limited to 15 minutes, is made only after a request from the Zeus app that matches a consent record the user created, and the values are held in memory only and never stored or logged. |
| Host access: `https://*/*`, `http://localhost/*`, `http://127.0.0.1/*` | The extension declares these only as _optional_ host permissions. At approval time it asks for the single origin concerned (for example `https://portal.example.org/*`), never for the whole pattern. | Browser-enforced scoping on top of the extension's own consent record: without the grant for that origin the extension cannot read its cookies or make a credentialed request to it. Plain `http` is accepted only for loopback addresses; session material is never released for other `http` sites.                                                                   |

There is **no** `<all_urls>`, no `host_permissions`, no content script, no `externally_connectable`, no `webRequest`, no `declarativeNetRequest`, no `tabs`, no `scripting`, no `activeTab`, no `contextMenus` and no `history`. Remote code is not loaded: the extension pages run under `script-src 'self'; object-src 'none'` and the build verifies that no bundle contains `eval` or `new Function`.

## Data handling summary

See [PRIVACY.md](PRIVACY.md). In one sentence: nothing leaves the user's computer except bytes the user asked Zeus to download, and the only recipient of session data is the Zeus app on the same machine.

## Reviewer notes

- The consent record is created only by a click in the extension's popup or options page (messages from any other sender are ignored: `sender.id` and the sender URL are checked), or by an event about an approval the extension itself displayed that a human decided in the Zeus terminal interface.
- Cross-origin redirects: a credentialed fetch that is redirected to a different origin is refused if the browser holds cookies for that origin and the user gave no consent for it.
- The in-browser fetch fallback performs an ordinary credentialed `fetch` exactly as if the user had clicked the link. It does not change request headers to disguise anything, does not solve challenges and reports a block page to Zeus as a block page.
